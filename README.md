# Personal Portfolio Website

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features

- **Modern Design**: Clean and professional design with smooth animations
- **Fully Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Dark/Light Mode**: Toggle between dark and light themes with persistent preference
- **Smooth Animations**: Engaging scroll animations and transitions
- **Sections**:
  - Hero section with call-to-action
  - About section with stats
  - Skills showcase organized by category
  - Experience timeline
  - Featured projects gallery
  - Contact information

## Technologies Used

- HTML5
- CSS3 (CSS Variables, Flexbox, Grid)
- Vanilla JavaScript
- No frameworks or libraries required

## Customization

To personalize this portfolio for your use:

1. **Update Personal Information** in `index.html`:
   - Replace "Your Name" with your actual name
   - Update the subtitle/title (e.g., "Software Engineer | Full Stack Developer")
   - Replace the hero description
   - Update your email, LinkedIn, and GitHub links in the contact section

2. **Update About Section**:
   - Modify the about text to reflect your background
   - Update the stats (years of experience, projects completed, etc.)

3. **Update Skills**:
   - Add/remove skill categories
   - Update technologies to match your skill set

4. **Update Experience**:
   - Replace placeholder companies and positions
   - Update dates and achievements
   - Add or remove timeline items as needed

5. **Update Projects**:
   - Replace project placeholders with your actual projects
   - Add project links, descriptions, and technologies used
   - Consider adding project images in the future

6. **Styling**:
   - Customize colors in `css/style.css` by modifying the CSS variables in `:root`
   - Adjust spacing, fonts, and other design elements as desired

## Local Development

Simply open `index.html` in your web browser. No build process required!

For a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js
npx serve
```

Then visit `http://localhost:8000`
